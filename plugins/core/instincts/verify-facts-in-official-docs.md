# Verify provider facts in official docs

## Action
Fetch the provider's official pricing or documentation page before answering, cite it, and mark any figure that only comes from a secondary source as unverified.

## Evidence
- 25.10.2026 (clicker): OpenAI TTS models turned out deprecated (shutdown 6.1.2027) only after reading the official guide; Azure prices could not be confirmed and were marked as such.

# Strip the attribution footer from GitHub posts

## Action
Never write "Generated by Claude Code" (or any AI attribution) into a PR, issue or comment; right after creating a PR, read its body back and, if the connector appended such a footer, remove it with update_pull_request and confirm it is gone.

## Evidence
- 25.10.2026 (clicker PR #18): the connector appended "Generated by Claude Code" to the PR body although it was not in the text sent; Matus: "To nikdy nepíš".
